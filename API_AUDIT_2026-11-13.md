# NOVA AI — API and Provider Rights Audit

**Reviewed:** 13 November 2026 (Asia/Kolkata)  
**Branch:** `fix/nova-home-learn-first-mobile-20261109`  
**Scope:** Source-derived API inventory, route guards, rate limits, provider terms and transferability. This is a technical diligence record, not legal advice or a vendor licence approval.

## Executive decision

**API audit: IN PROGRESS. Production: NO-GO.**

The source contains no active provider credentials in `.env.example`. The current Staging smoke returned HTTP 200 for `/health`, homepage and entry assets, but `GET /api/config` returned HTTP 503 because no AI chat provider is configured. Runtime logs confirm `NOVA_API_AUTH_REQUIRED` is disabled. No paid provider request was made during the Staging smoke.

Several providers currently used or referenced by the server have non-commercial, undocumented, or restricted rights. A publicly reachable endpoint is not proof of permission for a commercial product or for transfer to an acquirer. Do not enable public customer traffic, paid provider keys, or provider-dependent claims until each relevant right is documented.

| Route | Purpose | Auth behaviour | Source-level guard / known limitation |
|---|---|---|---|
| `GET /health` | Process readiness/liveness | Public | Returns process state; does not test external providers. |
| `GET /api/config` | Client provider/config bootstrap | Always public | Returns HTTP 503 when no compatible AI provider is configured. |
| `GET /api/feed` | Curated news/RSS feed | Always public | Read-only feed; per-process global API rate limit still applies. |
| `POST /api/chat/completions` | AI chat | Protected only when `NOVA_API_AUTH_REQUIRED=1` | JSON body limit 6 MB; history/token caps; providers attempted in configured order. |
| `POST /api/transcribe` | Speech-to-text | Protected only when auth gate enabled | Raw body limit 8 MB; uses configured LLM/Groq transcription endpoint. |
| `POST /api/search` | General web search | Protected only when auth gate enabled | Query limited to 400 characters; Tavily path is unavailable without a key. |
| `POST /api/live` | Intent-aware live retrieval | Protected only when auth gate enabled | Query limited to 500 characters; process-local 24/minute limit and concurrency cap (default 5). |
| `POST /api/image` | Image job submission | Protected only when auth gate enabled | Prompt limited to 1,000 characters; 3 jobs per 10 minutes per process-local user/IP bucket; queue cap 80. |
| `GET /api/image/status/:id` | Image job polling | Protected only when auth gate enabled | Authenticated job is bound to user ID; jobs exist in process memory only. |
| `GET /api/live/selftest` | Operator provider diagnostics | Protected only when auth gate enabled | Returns 404 unless `LIVE_SELFTEST_ENABLED=1`; process-local 4/minute limit. |
| Static/PWA routes | HTML, JS, icons, manifest, service worker, demo files | Public | Explicit route allowlist; no generic public-directory mount. |

### Authentication and request limits

- `NOVA_API_AUTH_REQUIRED` defaults to `0`; when disabled, the account token is not required by Express. Browser token forwarding does not itself secure the API.
- The first Express `/api` limiter is 60 requests/minute per IP in a process-local `Map`.
- Live retrieval is 24 requests/minute per verified user (or IP while auth is off), also process-local. Concurrent live retrieval defaults to 5.
- Image jobs are limited to 3 per 10 minutes per verified user (or IP while auth is off), process-local, with a global in-process queue cap of 80.
- Provider self-test is limited to 4/minute per IP and is disabled by default.
- These controls are not durable quotas, monthly usage accounting, plan entitlements, hard provider-spend caps, or cross-instance abuse protection.

## 3. Cost and router findings

1. **Paid search calls were previously parallel.** If Tavily and Brave keys were both present, the old `webSearch` used `Promise.any` over multiple provider promises. More than one paid request could start for a single user question.
2. The candidate now uses `nova-search-router.js` to attempt configured search providers sequentially and stops after the first usable result. Tavily is attempted before Brave. DuckDuckGo HTML scraping is removed from the fallback chain.
3. Tavily response caching is no longer shared by default. Cross-user caching requires `TAVILY_SHARED_CACHE_ALLOWED=1`, which must only be enabled after written permission is obtained from Tavily. The example defaults to `0`.
4. Brave results are called directly by the router and are not put into NOVA's shared result cache.
5. This change reduces duplicate provider calls but is **not** a global rupee spend cap, per-user monthly quota, provider quota reconciliation, circuit breaker or admin cost dashboard.
6. The provider self-test is not a 50-query bake-off and is not cost telemetry. No paid search key is configured in Staging, so no live paid-provider measurement was performed.

## 5. Security and release requirements still open

- Enable Auth in Staging only after the login UX and valid/missing/malformed/invalid/expired token tests pass. Auth remains disabled in the current Staging runtime.
- Implement durable per-user daily/monthly quotas, provider usage accounting, explicit plan entitlements, spend ceilings and cache-only mode at the cap.
- Verify provider commercial rights, retention/data processing, attribution, cache/redistribution limits and account assignment per provider. An API credential is not assumed transferable with the source code.
- Add provider circuit breakers and usage/cost logs; distinguish direct provider success from fallback success in diagnostics.
- Review RSS publisher rights and media/image licences record-by-record.
- Test actual Staging route behavior after a provider has been approved and configured; do not trigger paid calls for tests.
- The user is under 18. Some provider contracts expressly require users to be 18+ (including GroqCloud and Tavily). Do not attempt to bypass age terms. A responsible adult and qualified counsel must review and manage any eligible vendor agreement/account.
